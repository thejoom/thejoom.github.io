## 운영 노트

여러 도구와 역할을 나눠 사용할 때는 기록 가능한 단위로 작업을 쪼개는 것이 중요합니다.

### 샘플 체크리스트

- 지시 범위를 먼저 확인합니다.
- 결과물을 실제 파일로 검증합니다.
- 링크와 메타데이터를 함께 확인합니다.

| 역할 | 책임 |
| --- | --- |
| Controller | 방향 설정과 검증 |
| Worker | 제한된 범위 구현 |
| Reviewer | 결과 점검 |
