홈페이지 제작은 화면을 만드는 일만이 아닙니다. 방문자가 내용을 이해하고 문의까지 이어질 수 있도록 화면과 문구의 흐름을 함께 정리합니다. 다만 결제, 배송, 외부 서비스 연동처럼 운영 방식에 따라 달라지는 항목은 먼저 범위를 확인해야 합니다.

## 기본으로 함께 정리하는 범위

목적과 필요한 정보를 들은 뒤, 페이지 구성과 문구의 초안을 잡습니다. 모바일과 PC에서 읽기 편한 반응형 화면을 기준으로 만들고, 문의를 받을 방법이 필요하면 해당 흐름도 함께 검토합니다. 기존 사이트를 손보는 경우에는 유지할 내용과 바꿀 내용을 먼저 나눕니다.

| 구분 | 함께 정리하는 내용 | 먼저 확인할 내용 |
| --- | --- | --- |
| 화면 | 페이지 구성, 반응형 화면, 문구 흐름 | 필요한 페이지와 자료의 양 |
| 문의 | 문의가 이어지는 동선과 입력 항목 | 받을 방법과 담당자 |
| 기존 사이트 | 유지할 내용과 개선할 부분 | 현재 제작 방식과 접근 가능 여부 |

## 별도로 범위를 정하는 항목

쇼핑 기능, 예약 방식, 회원 기능, 관리자 기능, 외부 도구 연결은 필요한 정도가 서로 다릅니다. 같은 이름의 기능이라도 운영 절차와 데이터가 다르면 구현 범위도 달라집니다. 그래서 처음부터 기능 목록을 크게 적기보다, 실제로 누가 어떤 순서로 쓰는지 확인하는 편이 정확합니다.

### 진행은 이렇게 시작합니다

1. 업종과 사이트의 목적을 듣습니다.
2. 필요한 화면과 우선순위를 정리합니다.
3. 화면과 문구의 초안을 확인합니다.
4. 수정할 내용을 반영해 운영에 맞게 다듬습니다.
