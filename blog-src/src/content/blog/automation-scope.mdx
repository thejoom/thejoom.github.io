반복 규칙이 있는 업무라면 대부분 자동화 가능성을 검토할 수 있습니다. 같은 형식의 데이터를 옮기거나 정리하고, 정해진 조건에 따라 처리하는 일은 프로그램으로 줄일 수 있습니다. 다만 판단 기준이 사람마다 다르거나 매번 입력 형식이 달라지는 일은 규칙부터 정해야 합니다.

## 자동화가 잘 맞는 업무

엑셀의 반복 작업, 수기로 모은 자료의 정리와 취합, 필요한 데이터 수집, 관리자 화면에서 되풀이하는 처리가 대표적입니다. 간단한 웹서비스나 다른 서비스와의 연결도 업무 흐름이 분명하면 함께 검토할 수 있습니다. 목표는 큰 시스템을 만드는 것이 아니라, 지금 반복하는 일을 줄이는 것입니다.

| 업무 상태 | 자동화 검토 | 먼저 정할 것 |
| --- | --- | --- |
| 같은 작업을 자주 반복 | 적합 | 입력과 결과의 형식 |
| 조건에 따라 분류 | 적합 | 조건과 예외 처리 |
| 사람의 판단이 매번 다름 | 규칙 정리 후 검토 | 판단 기준과 승인 방식 |
| 외부 서비스 자료 사용 | 연결 가능 여부 확인 | 접근 권한과 제공 방식 |

## 안 되는 일보다, 아직 정해지지 않은 일이 있습니다

자동화가 어려운 경우는 대개 기술의 문제가 아니라 기준이 없는 경우입니다. 누가 어떤 자료를 넣고, 어떤 결과가 맞는지, 예외가 나면 누가 판단하는지부터 정리해야 합니다. 이 과정이 있으면 필요한 기능을 줄여서 먼저 시작하고, 운영하면서 넓히는 선택도 가능합니다.

### 진행 과정

1. 현재 일을 하는 순서를 설명합니다.
2. 반복되는 부분과 예외를 구분합니다.
3. 우선순위가 높은 범위를 정리합니다.
4. 적용한 뒤 실제 업무 흐름을 확인합니다.
