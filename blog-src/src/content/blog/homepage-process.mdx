홈페이지 제작은 «무엇을 보여 줄지 정하기 → 화면으로 확인하기 → 만들기 → 공개하고 검색에 올리기» 순서로 진행합니다. 각 단계에서 결정할 것을 미리 알면 중간에 다시 돌아가는 일이 줄어듭니다.

## 1. 목적과 대상 정리

처음에는 몇 가지 질문만 드립니다. 무엇을 알리려는지, 누가 볼지, 방문자가 마지막에 무엇을 하길 바라는지입니다. 메뉴 구성이나 디자인 취향은 그다음 문제입니다.

## 2. 시안으로 먼저 확인

말로만 정하면 서로 다른 화면을 떠올리기 쉽습니다. 그래서 첫 화면 시안을 먼저 보여 드리고, 방향이 맞는지 확인한 뒤 범위와 견적을 정합니다. 사진이나 원고가 아직 없어도 받은 정보로 시안을 만들 수 있습니다.

## 3. 범위와 견적 확정

페이지 수, 필요한 기능, 원고와 사진 준비 상태를 기준으로 범위를 정합니다. 금액이 정해지는 기준은 [홈페이지 제작 비용](/blog/homepage-cost/)에 정리해 두었습니다.

## 4. 제작과 확인

확정한 범위대로 화면을 만들고, PC와 휴대폰에서 모두 확인합니다. 문구와 이미지 수정은 이 단계에서 함께 반영합니다. 링크, 문의 폼, 화면 깨짐 같은 기본 항목은 공개 전에 따로 점검합니다.

## 5. 공개와 검색 등록

도메인을 연결해 공개한 뒤 구글 서치 콘솔과 네이버 서치어드바이저에 사이트를 등록합니다. 검색 결과에 실제로 반영되기까지는 보통 1~2주가 걸리므로, 등록 후 노출 여부를 한 번 더 확인합니다. 검색 노출이 걱정된다면 [검색에 안 뜨는 홈페이지, 무엇부터 봐야 하나요](/blog/seo-basics/)를 참고하세요.
